# CODE-Techwriting-fall26

A demo repository for the Fall 2026 technical writing class.

## Overview

This repository is a workspace for exploring different types of technical documentation in class. It includes README-writing resources and starter files for other documentation types. The collection can grow as the class discusses additional document types.

This is a documentation repository, not a software project; there is no application to install or run.

## Quick Start

1. Browse the [`docs/`](docs/) folder.
2. Open a Markdown file (`.md`) to read its contents in GitHub.
3. For your own class work, follow your instructor’s directions about forking and sharing changes.

## What’s in `docs/`?

- [`README-cheatsheet.md`](docs/README-cheatsheet.md) — a concise README checklist and section guide.
- [`README-from-claude.md`](docs/README-from-claude.md) — a longer guide to README structure and writing.
- [`README.md`](docs/README.md) — a README template with example sections.
- `about.md` — starter file labelled “About”; currently headings only.
- `code-comments.md` — starter file labelled “Code Comments”; currently headings only.
- `conceptual.md` — starter file labelled “Conceptual”; currently headings only.
- `how-to.md` — starter file labelled “How To”; currently headings only.
- `tutorial.md` — starter file labelled “Tutorial”; currently headings only.

## Using This Repository

The files in `docs/` are resources and starting points for class work. Some are more complete than others; check each file to see what it currently contains. Follow your instructor’s directions for which materials to read or edit and how to share your work.

## Support

For course-specific questions, use the communication channel provided by your instructor.
